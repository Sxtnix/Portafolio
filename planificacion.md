# Planificación del Portafolio

## Objetivo

Crear un portafolio profesional que presente mi perfil como desarrollador y evidencie los aprendizajes de la unidad: HTML5 semántico, CSS responsive y validación con JavaScript.

## Público objetivo

Reclutadores, docentes evaluadores y otros desarrolladores que revisen mi trabajo en GitHub.

## Secciones

Inicio, Sobre mí, Habilidades, Proyectos y Contacto.

## Tecnologías

- HTML5 semántico
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (validación de formulario)

## Boceto

```text
Header (logo + nav)
Hero (presentación)
Sobre mí
Habilidades (grid de tarjetas)
Proyectos (lista con tags y links)
Contacto (formulario)
Footer (nombre + GitHub)
```

## Requisitos principales

- HTML5 semántico y válido
- CSS externo y responsive
- Formulario validado con JavaScript
- Repositorio en GitHub con commits progresivos
- Sitio desplegado públicamente
