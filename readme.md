# Portafolio Profesional — Diego Andrés Díaz Hernández

Portafolio web personal desarrollado para la Evaluación Parcial 1 del módulo Desarrollo Full Stack II.

## Descripción

Sitio de una sola página con mi presentación profesional, habilidades, proyectos y un formulario de contacto validado. Incluye las secciones Inicio, Sobre mí, Habilidades, Proyectos y Contacto.

## Tecnologías utilizadas

- **HTML5 semántico**: etiquetas `header`, `nav`, `main`, `section`, `article` y `footer`.
- **CSS3 externo**: `styles.css`, con **Flexbox** y **Grid** para el layout, y **media queries** para diseño responsive (computador, tablet y móvil).
- **JavaScript**: `script.js`, con validación del formulario de contacto (nombre, correo y mensaje) y mensajes de error en pantalla.

## Estructura del proyecto

```text
Portafolio/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Cómo ejecutar el proyecto

1. Clonar este repositorio.
2. Abrir `index.html` en el navegador.
